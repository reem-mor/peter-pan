# INC-2119 - Cache stampede after redis restart (2026-03-08)

**Severity:** P2 - **Duration:** 38 min - **Class:** cache

**What happened:** Planned redis restart during peak traffic collapsed hit rate to 4 percent; database CPU saturated within 3 minutes; p95 up 9x.

**Resolution:** Progressive cache warming + request coalescing restored hit rate; DB recovered.

**Lessons:**
- Cache restarts are now scheduled off-peak with staged replica cycling.
- Added stale-while-revalidate to the three hottest keys.
