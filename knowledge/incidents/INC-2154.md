# INC-2154 - Queue backlog from poison message (2026-03-27)

**Severity:** P3 - **Duration:** 2 h 10 min - **Class:** queue

**What happened:** A malformed event crashed consumers in a restart loop; the partition stalled; message age p99 reached 40 minutes.

**Resolution:** Moved the poison message to DLQ manually; consumers drained the backlog in 35 minutes.

**Lessons:**
- Added a dead-letter policy so a single bad message cannot stall a partition again.
- Consumer crash-loop alert now fires at 3 restarts in 5 minutes.
