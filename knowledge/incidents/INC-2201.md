# INC-2201 - DNS outage from network policy change (2026-04-19)

**Severity:** P1 - **Duration:** 27 min - **Class:** connectivity

**What happened:** A tightened network policy blocked kube-dns for one namespace; all cross-service calls in that namespace failed with host-not-found.

**Resolution:** Policy rollback restored resolution; verified with in-namespace dig checks.
