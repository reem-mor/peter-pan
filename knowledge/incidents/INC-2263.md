# INC-2263 - Memory leak in session cache v2.3 (2026-05-21)

**Severity:** P2 - **Duration:** 3 days intermittent - **Class:** resource_exhaustion

**What happened:** Checkout pods OOMKilled every 6-8 hours; heap diffs showed unbounded session cache growth when the eviction job was disabled by a config regression.

**Resolution:** Re-enabled the eviction job; rolling restarts as interim mitigation; fix shipped in v2.3.1.

**Lessons:**
- Eviction job status is now a healthz dependency for checkout.
- This incident is the source of the checkout-oom runbook v2.3 warning.
