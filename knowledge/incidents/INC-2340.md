# INC-2340 - Certificate expiry on partner API (2026-06-15)

**Severity:** P2 - **Duration:** 1 h 05 min - **Class:** security

**What happened:** Partner-facing mTLS cert expired; the T-14d expiry alert had been routed to a decommissioned channel.

**Resolution:** Rotated the cert via cert-manager; verified the chain with openssl; re-routed the alert.

**Lessons:**
- Alert-channel routing is now part of quarterly alert audits.
- Sibling certs from the same batch were rotated proactively.
