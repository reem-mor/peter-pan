Optimization tips

    Token playbook

    • Route by tier. Deterministic floors + local predictor first; call the commercial model only for synthesis.
    • Trim retrieval. Cap RAG chunks per story; irrelevant context is the #1 input-token leak.
    • Cache prompts. Stable system prompts + versioned templates make prompt caching effective.
    • Bound the loop. Step + token budgets on every LangGraph run; exhaustion = deterministic fallback, not retry storms.
    • Meter everything. No unlogged LLM call — this dashboard is only as honest as log_usage() coverage.
